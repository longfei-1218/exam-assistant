# 备考助手（exam-assistant）

## 安装

```powershell
pnpm install
```

## 启动

同时启动前后端：

```powershell
pnpm dev
```

| 服务 | 地址 |
| --- | --- |
| 前端 | http://127.0.0.1:5173 |
| 后端 | http://127.0.0.1:3001 |

分别启动：

```powershell
pnpm dev:api
pnpm dev:web
```

## Prisma Studio

```powershell
pnpm --filter @exam/api exec prisma studio
```

默认地址：http://localhost:5555

一、单项选择题

1. 素质教育的重点是培养学生的（　）。
A. 应试能力
B. 创新精神和实践能力
C. 记忆能力
D. 竞争意识
答案：B
解析：素质教育以培养学生的创新精神和实践能力为重点。

2. “学高为师，身正为范”主要体现了教师职业道德中的（　）。
A. 爱国守法
B. 爱岗敬业
C. 为人师表
D. 终身学习
答案：C
解析：为人师表要求教师严于律己、以身作则，在品行和学识方面成为学生的榜样。

3. 根据《中华人民共和国教育法》，中华人民共和国公民有受教育的（　）。
A. 权利
B. 义务
C. 权利和义务
D. 自由
答案：C
解析：《教育法》规定，中华人民共和国公民有受教育的权利和义务。

4. 下列不属于“四书”的是（　）。
A. 《大学》
B. 《中庸》
C. 《论语》
D. 《诗经》
答案：D
解析：“四书”指《大学》《中庸》《论语》《孟子》，《诗经》属于“五经”。

5. 教师在教育教学活动中应当平等对待学生，主要体现了（　）。
A. 教育公正
B. 教育惩罚
C. 教育竞争
D. 教育筛选
答案：A
解析：平等对待学生、尊重学生差异，体现了教育公正的基本要求。

6. 小学生王某在课堂上多次违反纪律，教师最恰当的处理方式是（　）。
A. 当众辱骂王某
B. 让王某停课一周
C. 课后了解原因并进行教育引导
D. 要求其他学生孤立王某
答案：C
解析：教师应当尊重学生人格，了解学生行为背后的原因，采用适当方式进行教育引导。

二、多项选择题

7. 素质教育的基本内涵包括（　）。
A. 面向全体学生
B. 促进学生全面发展
C. 促进学生个性发展
D. 以培养创新精神和实践能力为重点
答案：A、B、C、D
解析：素质教育面向全体学生，促进学生全面发展和个性发展，并以培养创新精神和实践能力为重点。

8. 下列属于《中小学教师职业道德规范》内容的有（　）。
A. 爱国守法
B. 爱岗敬业
C. 关爱学生
D. 终身学习
答案：A、B、C、D
解析：《中小学教师职业道德规范》包括爱国守法、爱岗敬业、关爱学生、教书育人、为人师表和终身学习。

三、判断题

9. 教师可以根据学生的考试成绩安排座位，并对成绩较差的学生进行区别对待。
答案：错误
解析：教师应当平等对待学生，不能以考试成绩为依据歧视学生。

10. 教师可以以击打、刺扎等方式直接造成学生身体痛苦，以此达到教育惩戒的目的。
答案：错误
解析：教育惩戒不得以击打、刺扎等方式直接造成学生身体痛苦，不得侮辱学生人格尊严。
