路由与参数

  • 题型作为 query 参数带入下一步：单个 → P6，批量 → P7，换页不重选。
  • 批量导入不支持语音，语音只作输入辅助——约束写进页面文案。

为什么批量标「推荐」

AI 解析是本产品的核心差异点，默认引导用户走批量路径；单个导入是兜底，不该抢主入口。

题型 → 表单差异

  • 单选：A–D 选项输入 + 圆形答案徽标（点圆标即设为正确答案）。
  • 多选：同上，但圆标允许多个同时点亮。
  • 填空：选项区收起，题干内用 __ 标记空位，答案为文本输入。
  • 简答：答案用文本域，标注「将使用 AI 按采分点判分」。

校验与保存

  • 提交前校验：题干非空、答案与题型自洽（单选答案必须在选项内）。
  • 题干归一化 hash 查重，重复时提示「已有同题」并阻止。
  • 「保存并继续」清空表单保留类目与题型，适合连续补录。

校对行可编辑项

  • 题型下拉（单选 / 多选 / 填空 / 简答）可改；类目下拉从已有类目中选，选不到可建议新建。
  • 置信度 < 0.7 整行琥珀高亮；去重命中显示「与已有题目重复」且默认不勾选。
  • 点题干展开完整预览：选项、答案、解析均可改后再入库。

工程约束（页面必须体现）

  • 解析中禁止重复提交，按钮置灰；进度用 SSE / 轮询，显示「已解析 x/y 段」。
  • 单次导入上限 50 题，超限提示分批粘贴。
  • 解析失败 → 顶部 Banner 提示，保留「去单个录入」兜底入口（P6）。
  • 入口三选一：粘贴文本（一期）/ 拍照识别（二期）/ 文件导入（二期），未上线入口置灰不阻断主流程。
  • 批量选择：全选 / 仅选高置信度。
校对是硬性环节，不是可选项——AI 一次解析 30 题必有错，没有这一步题库三个月后就是脏的。
