# 备考助手一期实施计划

> 版本：v1.0  
> 日期：2026-11-09  
> 项目名：exam-assistant  
> 当前目录：exam-assiant

## 1. 一期边界

一期按 B 方案执行：

1. M1：登录、考试、类目、题目 CRUD、客观题作答、错题本、统计。
2. M2：AI 文本导入、解析、校对、去重、类目归并、导入任务进度。
3. M3：简答题 AI 判分、采分点反馈、超时降级、申诉翻转、统计性能优化。

一期不包含：

- 真实邮件发送和邮箱验证
- PDF、Word、Excel 文件解析
- 算法题和代码题
- AI 变式题和自动组卷
- SM-2、FSRS 等间隔重复算法
- 练习进度跨页面或跨设备恢复
- 题目分享、社区、排行榜
- 移动端原生应用

## 2. 已确认决策

| 决策项 | 结论 |
| --- | --- |
| 产品形态 | 移动优先的响应式 Web |
| 部署目标 | 先支持本地 demo，同时保留后续部署空间 |
| LLM | 一期 DeepSeek `deepseek-chat`，抽象 Provider 接口 |
| 后端 | 纯 TypeScript 单体 |
| 登录 | 邮箱密码注册登录，找回密码只做 UI 和 token 流程 |
| AI 异步导入 | `import_jobs` 表加前端 1.5 秒轮询 |
| 练习进度 | 不持久化，不恢复进度 |
| ORM | Prisma |
| 验证标准 | 后端单测、契约测试、Playwright 冒烟测试 |
| 初始内容 | 不内置种子题库 |

## 6. LLM Provider 抽象

### 6.1 Provider 接口

```ts
interface LLMProvider {
  generateStructured<T>(input: {
    prompt: string;
    schema: ZodSchema<T>;
    signal?: AbortSignal;
    metadata?: Record<string, unknown>;
  }): Promise<T>;
}
```

Provider 层统一处理：

- 超时
- 结构化输出
- Schema 校验
- 失败重试
- token 统计
- prompt 版本
- 模型名称和供应商名称

一期实现 `DeepSeekProvider`。后续新增其他供应商时，只新增 Provider，不修改业务层。

### 6.2 环境变量

```text
LLM_PROVIDER=deepseek
LLM_MODEL=deepseek-chat
DEEPSEEK_API_KEY=your_key
```

## 7. AI 导入处理链

1. 前端提交原始文本，创建 `import_jobs`，状态为 `queued`。
2. worker 将文本按约 3000 字分块，并发处理 2 到 3 块。
3. 每块携带上一块最后一题的上下文。
4. DeepSeek 返回结构化题目数组。
5. Schema 校验失败时回灌错误并重试，最多两次。
6. 规则校验题型、选项、答案、空位和简答内容。
7. 根据 `stem_hash` 去重。
8. 将已有类目列表塞入 prompt，完成类目归并。
9. 单次导入最多 50 题，超过时提示分批。
10. 解析完成后状态变为 `ready`，由用户校对。
11. 用户点击确认导入后，才批量写入 `questions`。

前端通过 `GET /api/imports/:id` 每 1.5 秒轮询一次，显示已解析分段和题目数量。

## 8. 简答判分

### 8.1 处理流程

1. 答案为空或少于 5 字时直接判错，不调用 LLM。
2. 构造题干、参考答案和采分点 rubric。
3. DeepSeek 一次调用返回 JSON。
4. 校验分数、命中点、遗漏点、点评和是否正确。
5. 落库 `attempts`。
6. 前端显示正确或错误、命中点、遗漏点、点评和申诉按钮。

### 8.2 过关规则

同时满足以下两个条件才判定过关：

- `score >= 60`
- 采分点覆盖率 `>= 0.6`

### 8.3 容错与成本

- 按 `hash(题干 + 用户答案)` 缓存结果。
- 10 秒未返回时降级为自评。
- 用户可翻转结果，写 `overridden` 并保留原始 AI 判定。
- 统计日均调用量和 token 使用量。

## 11. 风险与处理

| 风险 | 处理 |
| --- | --- |
| DeepSeek JSON 不稳定 | Provider 层统一 Schema 校验和重试 |
| 长文本解析不完整 | 分块加跨块上下文 |
| 简答误判 | 申诉翻转并保留原始样本 |
| 统计 N+1 | 使用 `category_stats` 异步重算 |
| 重复导入造成重复题目 | 使用 `stem_hash` 去重 |
| 任务服务重启后卡住 | 启动时把 `processing` 任务恢复为 `queued` |
| 模型成本失控 | 限制单次导入 50 题，记录 token 使用量 |
